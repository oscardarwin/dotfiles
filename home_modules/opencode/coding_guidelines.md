# Coding Guidelines
Don't write comments unless absolutely necessary.
Don't use abbreviated variable names. Use full words and make the variable name match the type of data the variable will hold
Use type aliases to improve readability of types.
Avoid nesting lots of operations - assign to variables instead.
Use a functional style as much as possible. Avoid mutable state as much as possible.
Keep functions small with good names that describe their intent.

## Rust
Only run clippy and fix any errors before a commit.
